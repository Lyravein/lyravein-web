01 · About

Night-shift builder

I'm a developer from Pasuruan, Indonesia, currently studying Informatics Engineering at Universitas Muhammadiyah Malang. Most of what I make happens late at night: Discord bots that never sleep, games in Unity, and desktop tools that scratch my own itches.

I like software that runs quietly and reliably: a download manager in Go, a bot that has been online for months on a repurposed Android phone, bridges that keep other tools talking to each other. If it can be automated, scripted, or shipped, I'm probably already building it.
