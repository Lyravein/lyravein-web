01 / About

Night-shift builder, from Pasuruan.

I'm a developer from Pasuruan, Indonesia, currently studying Informatics Engineering at Universitas Muhammadiyah Malang.

Most of what I build happens late at night: multiplayer game prototypes in Unity, modern web applications, and backend systems that run behind the scenes.

I like software that runs quietly and reliably: automated telemetry pipelines, self-hosted services running 24/7 on dedicated hardware, and bridges that connect complex tools together. If a workflow can be scripted, automated, or polished, I am probably already writing code for it.
